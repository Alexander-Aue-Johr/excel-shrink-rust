Workbook sources

Names are matched by relative path, then by unique filename. Ambiguous matches remain explicit failures. Visual comparison currently requires XLSX on both sides.

Processing steps

Steps run in order. Each program receives separate arguments. A file step may run several processes; folder and ZIP steps run once per stage.

For an XLS → XLSX conversion, explicitly select the conversion step as baseline. The subsequent transformations are compared; that conversion itself is outside visual coverage.
