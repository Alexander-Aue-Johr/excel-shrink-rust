# Native evidence audit for the opening and memory cases

The companion JSON inventories four original identities across five cleaners.
It joins retained report and identity-file digests, canonical member manifests,
native policies and exact common-rectangle pixel observations. Tool-profile
verification and the complete resource-output lineage remain explicit gates.

## Metric and scope

For each retained image pair with equal measured top-left origins, D counts
pixels whose normalized RGBA values differ. N counts the common rectangle's
pixels. Width and height are the minima of the two native dimensions. No scaling,
registration, perceptual tolerance or alteration of the source verdict occurs.
Different dimensions and recorded geometry findings in measured rectangles
have separate counters. Missing images and unmatched origins receive no N.
Repeated and overlapping captures contribute repeated pixel observations.

Four synthetic controls cover equal pixels, a one-channel change, an alpha-only
change, and a changed pixel outside the shared rectangle. Across retained
same-dimension image pairs, the exact differing-pixel counts agree with the
source report's pixel-difference flags. The read-only audit completed in
457.5 seconds with a 372,060,160-byte aggregate job-commit peak, below its 2 GiB
ceiling. An 8 GiB system RAM/commit reserve remained active.
