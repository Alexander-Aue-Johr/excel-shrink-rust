# Range capture

Strategy F uses precomputed Rust metadata and validated Excel geometry. The selected
method is .NET/Selective/32 MP with gridlines disabled, visible context and strict
canonical pixels. Strategies A–E and the VBA chart adapter remain individual
references with their stated bounds/raster differences. Use the common
[GUI/CLI](../README.md); `run.ps1` in this directory is the low-level worker adapter.
