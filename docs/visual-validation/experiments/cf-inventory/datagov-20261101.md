# Data.gov conditional-formatting inventory, 2026-11-01

## Observed run

The release inventory completed all **9,117 XLSX workbooks**, scanning **47,032
worksheet XML entries** containing **155,607,702,871 uncompressed XML bytes**.
Elapsed time was **852.39 seconds (14 min 12 s)**, with **zero analysis errors**.
This is one end-to-end local run, not a controlled cold-cache benchmark.

It found **20,935 conditional-formatting blocks containing 31,741 rules**.
All application ranges were recognized except three pivot-formatting blocks
described below. Code for the run is in `bdbb196` and `23ba663`; the local
`provenance.json` also records the exact release executable SHA-256.

Local results, intentionally not committed:

## Classification is not an invariance proof

**12,122 blocks (57.9%)** are in the narrow literal-operand `cellIs` family,
without unmodeled block/rule content. They are eligible for a later comparison
of rules, priorities, values, effective formatting and dependencies. They have
**not** been proven visually unchanged by this inventory.

The remaining **8,813 blocks** comprise:

| Reason | Blocks |
| --- | ---: |
| Unsupported rule semantics or nonliteral operands | 6,581 |
| Unmodeled block content | 2,081 |
| Prefixed/extension XML needing namespace review | 148 |
| Application range absent/unparsed | 3 |

Rule types include `cellIs`, `colorScale`, `expression`, `containsText`,
`duplicateValues`, `dataBar`, `containsBlanks`, `containsErrors`, `beginsWith`,
`endsWith`, `iconSet`, `top10`, `uniqueValues` and `aboveAverage`.

## Dominant nominal fallback family

Costs use a **256-row × 32-column fixed grid**, without clipping to visible/used
content. Overlapping references are summed. These numbers rank nominal regions;
they are **not actual Office.js tile counts or measured capture durations**.

Each unsupported block is assigned once to the following display families:

The INDIRECT family accounts for **96.3% of the known nominal proxy among
unsupported blocks**. This does not establish a 96.3% runtime opportunity.
Seventeen blocks in three small building-model workbooks dominate this family:

- `refbldgprimaryschoolnew2004v1.35.0si_f117fae5fbf2.xlsx` (source 8288)
- `refbldgprimaryschoolpost1980v1.35.0si_88791eb8fcfd.xlsx` (source 8289)
- `refbldgprimaryschoolpre1980v1.35.0si_aced77ed8ed9.xlsx` (source 8290)

The other two blocks are in `EFS_Rhodes_2016_IGP2010_QAQC_9725ccb0f1a9.xlsx`
(source 2054) and contribute only 16 nominal tiles.

A representative `cellIs` / `notEqual` operand, with XML entities decoded for
readability, is:

```text
INDIRECT("Dummy_for_Comparison1!"&ADDRESS(ROW(),COLUMN()))
```

Applications include almost the entire Excel grid, sometimes exactly
`A1:XFD1048576`. The three building-model inputs list only `BuildingSummary`,
`ZoneSummary`, `LocationSummary`, `Picture` and `Schedules`; their workbook sheet
lists do not contain the named `Dummy_for_Comparison…` targets. This is a useful
lead for a narrow semantic/Excel experiment, not an implemented skip or a proof
that Excel cannot apply the rule. General INDIRECT evaluation is unnecessary
to investigate this exact recurring template first.

## Three ranges requiring separate fallback treatment

`first_6_weeks_post_fumigation_16f176f0c073.xlsx` (source 7052) contains three
blocks with `pivot="1"` and **no `sqref`**:

- `xl/worksheets/sheet2.xml`, block indices 0 and 2
- `xl/worksheets/sheet6.xml`, block index 0

Each is a color scale with min / 50th percentile / max thresholds. The XML was
read successfully, but no ordinary application range could be established.
They must not be treated as empty or safe. Their complete nodes and original
workbook are retained for pivot-specific analysis or a conservative fallback.

## Evidence retention and verification

Every discovered node fits the inline tier: **20,935 complete raw XML nodes,
5,217,780 bytes total**, largest node **5,314 bytes**. All raw UTF-8 byte lengths
match their source spans. No node was discarded because of size.

**753 original XLSX files**, totaling **4,226,524,593 bytes**, are also retained.
They provide ancestor namespaces, styles, names, pivot parts and other context
that the initial metadata extraction may not understand.

Focused checks before the full run:

- Four small workbooks / 18 sheets / 8.98 MB XML: about 0.07 seconds, no errors.
- Largest XLSX plus a large Lysimeter workbook: two files / six sheets /
  3.83 GB XML: 17.15 seconds, no errors.
- Five inventory tests, eight streaming-parser tests and eighteen targeted
  comparison tests passed. The two previously verified large targeted-comparison
  tests were not repeated for this change.
- Synthetic raw-node recovery passed for inline, external-node and retained-source
  storage, including a node over 1 MiB. A real Data.gov node was also recovered
  byte-for-byte with the reviewer extraction tool.

No workbook was opened in Excel, shrunk or recalculated. The inventory does not
change capture selection or resume the visual corpus run.
